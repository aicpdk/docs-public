## Who can edit

Members with the editor role can edit these pages. To get it, ask your department admin, who asks a developer.

## How to edit

1. Open [docs.aicpdk.com/admin/](https://docs.aicpdk.com/admin/).
2. Log in.
3. Choose a page, change the text and save.
4. The change is live in about a minute.

## Writing in Markdown

Pages are written in Markdown:

- `## Heading` makes a heading.
- `**bold**` makes bold text.
- A line starting with `- ` makes a list item.
- `[text](/organisation/overview/)` makes a link.

Do not use raw HTML. It is not shown on the site.

## Images

Add images through the media library in the editor. Do not paste images from elsewhere.

## Keep it public-safe

This site is public. Never write personal names, emails, phone numbers or security details here. Use roles instead.

Use the words in the [glossary](/organisation/glossary/).
